# Paraú Investidor

Jogo multiplayer online para 2 a 6 jogadores, com entrada, sala de espera e partida em telas separadas.

Execute `npm install` e `npm start`. O comando de início gera o tabuleiro e as cartas e inicia o servidor na porta indicada por `PORT` (3000 por padrão).

No navegador, crie uma sala, compartilhe o código e aguarde ao menos dois jogadores. O anfitrião inicia a partida. Atualizar a página restaura o acesso usando a sessão salva no navegador.

As artes originais do tabuleiro e títulos foram preservadas.
